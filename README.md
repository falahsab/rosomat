# متجر رسومات الرقمية (Rosomat Digital Store)

متجر إلكتروني متكامل للحلول والخدمات الرقمية، مطابق بنسبة 100% لتصميم متجر **رسومات الرقمية** (`rosomat.co/products/` و صفحة المنتج `Android-and-IOS-app-programming`).
المتجر مبني بملفات ستاتيكية (HTML5, Bootstrap 5.3 RTL, CSS3, JavaScript) ليعمل مباشرة وبشكل مجاني على **GitHub Pages**.

---

## 🌟 مميزات المتجر

1. **تصميم مطابق تماماً لمتجر رسومات**:
   - الهوية البصرية الرسمية والألوان (`#da4310`, `#cd2a35`, الخط العربي Cairo).
   - شريط إعلانات علوي، هيدر متجاوب، شريط التصنيفات، وبطاقات المنتجات ذات التأثيرات الجذابة.
   - صفحة منتج متكاملة بالخيارات والتسعير والتبويبات.

2. **الطلب المباشر عبر الواتساب**:
   - عند النقر على "اطلب الآن عبر الواتساب"، يتم تحويل العميل تلقائياً إلى محادثة واتساب مع رسالة جاهزة ومنسقة تحتوي على:
     - اسم المنتج
     - رمز المنتج (SKU)
     - الباقة أو الخيار المختار
     - الكمية
     - السعر الإجمالي بالعملة المختارة
     - رابط صفحة المنتج للتأكيد السريع.

3. **دعم 3 عملات مع التحويل اللحظي**:
   - ريال سعودي (**SAR - ر.س**)
   - دولار أمريكي (**USD - $**)
   - درهم إماراتي (**AED - د.إ**)
   - يتم تبديل الأسعار لحظياً في المتجر بدون إعادة تحميل الصفحة مع حفظ اختيار العميل في المتصفح.

4. **لوحة تحكم لإضافة وتوليد صفحات المنتجات (`admin.html`)**:
   - إدخال عنوان المنتج، الأسعار بالعملات الثلاث، الصور، والتفاصيل.
   - **توليد كود صفحة المنتج HTML فورياً**: زر لتحميل ملف HTML الجاهز لوضعه في مجلد `products/`.
   - **توليد سطر الـ CSV**: تحديث قاعدة بيانات المنتجات مع إمكانية تحميل ملف `products.csv` الجديد بضغطة زر.

5. **قاعدة بيانات خفيفة بملف CSV (`data/products.csv`)**:
   - صفحة المتجر الرئيسية تقرأ المنتجات ديناميكياً من هذا الملف، بمجرد إضافة سطر جديد للمنتج في الـ CSV يظهر فوراً في المتجر مع الفلترة والبحث.

## 🚀 طريقة رفع المتجر على GitHub Pages مجاناً

1. افتح حسابك على [GitHub.com](https://github.com) وأنشئ مستودعاً جديداً (New Repository) وليكن باسم: `rosomat-store`.
2. في جهازك، ادخل لمجلد المشروع وارفع الملفات باستخدام الأوامر التالية:
   ```bash
   git init
   git add .
   git commit -m "إطلاق متجر رسومات الرقمية"
   git branch -M main
   git remote add origin https://github.com/اسم_المستخدم_حقك/rosomat-store.git
   git push -u origin main
   ```
3. ادخل على صفحة المستودع في GitHub واضغط على **Settings** > **Pages**.
4. تحت قسم **Build and deployment**:
   - اختر **Deploy from a branch**.
   - اختر الفرع **main** ومجلد **/(root)**.
   - اضغط **Save**.
5. خلال ثوانٍ سيظهر لك رابط موقعك المباشر:
   `https://اسم_المستخدم_حقك.github.io/rosomat-store/`

---

## 🛠️ كيفية إضافة منتج جديد مستقبلاً:

1. افتح صفحة `admin.html` في متصفحك.
2. املأ بيانات المنتج (العنوان، الأسعار بالعملات الثلاث، الصورة، الوصف، الخيارات، ورقم الواتساب).
3. اضغط على **توليد كود صفحة المنتج وإضافته للـ CSV**:
   - اضغط زر **تحميل ملف [slug].html** وضعه في مجلد `products/`.
   - اضغط زر **تحميل ملف products.csv المحدث** واستبدله داخل مجلد `data/`.
4. ارفع التغييرات إلى GitHub (`git add . && git commit -m "add product" && git push`) وستظهر المنتجات الجديدة فوراً في متجرك!
