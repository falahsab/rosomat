خطوات رفع المتجر على GitHub وتفعيل GitHub Pages

1 رفع المجلد إلى مستودع GitHub

قم بإنشاء مستودع جديد (Repository) على حسابك في GitHub، ثم ارفع ملفات هذا المجلد:

git init
git add .
git commit -m "Initial store deployment"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
2 تفعيل الاستضافة المجانية (GitHub Pages)
  1. ادخل على صفحة المستودع في GitHub.
  2. انقر على تبويب Settings في الأعلى.
  3. من القائمة الجانبية اختر Pages.
  4. تحت قسم Build and deployment:
    • اختر Source: Deploy from a branch
    • اختر الفرع: main ثم مجلد: /(root)
  5. اضغط Save.
  6. خلال دقيقة واحدة سيكون متجرك متاحاً عالمياً برابط مثل:
    https://USERNAME.github.io/REPO_NAME/
